# Hotfix: Context Compaction Output Limit Overflow

**Date:** 2026-11-23
**Repository:** omlx-prompt-shrink / context-shrink.py

## Problem

51K token'lık bir bağlam özetlenirken `"Compaction summary reached the output token limit"` hatası alınıyordu. Model `Qwen3.6-35B-A3B-4bit` (oMLX, 64K context window) kullanılıyordu.

### Kök neden

`_summarize()` fonksiyonunda chunk budget dinamik hesaplanıyordu:

```python
chunk_budget = max(1024, max_context_tokens - summary_budget_tokens - 1024)
```

64K context window ile bu formül ~64K token'lık bir chunk budget veriyordu. 51K token'lık bağnam tek bir chunk'a sığıyordu ve model tümünü özetlemeye çalışırken kendi **output token limitini** aşıyordu (51K girdi → 4.1K çıktı bekleniyordu ama model tüm bağlamı output olarak döndürüyordu).

## Çözüm

### 1. Chunk budget'i sabit 4096 token'a düşürüldü

```python
chunk_budget = 4096  # fixed per-chunk cap
```

Her chunk maksimum 4096 token ile sınırlı. Böylece model her özet çağrısında output limitine sığdırabiliyor. 51K token bağlam artık ~12 küçük chunk'a bölünüp her biri ayrı özetleniyor, sonra birleştiriliyor.

**Neden 4096?** Modelin tipik output limitinin (genellikle 4K-8K) altında kalacak güvenli bir değer. Küçük chunk'lar daha fazla çağrı demek ama her çağrı output limitini aşmıyor.

### 2. Fallback response handling eklendi

Bazı sunucular (özellikle oMLX) output limitini aştığında hata dönmek yerine full prompt'u `choices` içinde geri gönderiyor. Bu durumda temiz bir hata fırlatmak yerine mevcut içeriği döndür:

```python
if "choices" in body and isinstance(body["choices"], list) and len(body["choices"]) > 0:
    content = body["choices"][0].get("message", {}).get("content", "")
    if content:
        return str(content).strip()
```

Bu fallback, model bazen output limitini aşıp kısmi özet döndürse bile compaction'ın tamamen başarısız olmasını engeller.

## Değişen Dosyalar

- `context-shrink.py`: `_summarize()` (chunk_budget) ve `_call_chat_completions()` (fallback)
- `~/.config/opencode/mcp/context-shrink.py`: MCP server kopyası aynı değişikliklerle güncellendi

## Notlar

- `summary_budget_tokens` varsayılan 512 — modelin özet için ayırdığı token bütçesi
- `max_context_tokens` varsayılan 32768, kullanıcı için 65536 (oMLX 64K window)
- Chunk budget, context window değil **özetlenecek bölümün** boyutuna göre belirlenmeli
